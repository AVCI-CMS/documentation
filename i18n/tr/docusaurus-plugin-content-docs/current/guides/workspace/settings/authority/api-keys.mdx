# API Anahtarları

**Menü Yolu:** `Çalışma Alanı > Ayarlar > Yetki > API Anahtarları`

:::info Yetki Gereksinimleri
API anahtarlarını görüntülemek ve yönetmek için **workspace:manage** yetkisine sahip olmanız gerekir.
:::

API Anahtarları modülü; çalışma alanınızı mağaza, mobil uygulama ve sunucu servisleriyle `x-avcicms-*` başlık standardı ve çift anahtar mimarisi üzerinden güvenli biçimde entegre etmenizi sağlar.

## Kimlik Bilgileri ve Başlıklar

### 1. İstemci Kimliği (`x-avcicms-client`)
- **Tanımlayıcı:** Çalışma alanınızın dış servislerdeki benzersiz UUID kimliğidir. Tüm harici API isteklerinde `x-avcicms-client` başlığı ile gönderilir.
- **Güvenlik:** Herkese açıktır; tarayıcı ve mobil uygulamalarda güvenle kullanılabilir.

### 2. Genel Anahtar (`x-avcicms-api-key`)
- **Format:** `pk_live_...`
- **Kapsam:** Tarayıcı ve mobil uygulamalar için güvenlidir. Yalnızca herkese açık okuma ve anonim görüntülenme yetkisi taşır.
- **Yenileme:** Anahtar alanı içindeki yenile ikonuna tıklayarak yeni bir Genel Anahtar üretebilirsiniz. Yeni anahtar üretildiğinde önceki anahtar anında geçersiz olur.
- **Zaman Takibi:** Oluşturulma ve son kullanım tarihleri kart başlığında gösterilir.

### 3. Gizli Anahtar (`x-avcicms-secret-key`)
- **Format:** `sk_live_...`
- **Kapsam:** Yalnızca sunucu tarafı işlemler (SSR, arka uç servisleri, zamanlanmış görevler ve webhook'lar) için kullanılır.
- **Tek Seferlik Gösterim:** Yeni üretilen anahtar onay penceresinde tam metin olarak **yalnızca bir kez** gösterilir. Güvenli bir yere kaydedin; sonrasında güvenlik gereği maskeli olarak görünür.
- **Yenileme:** Anahtarın sızdığından şüpheleniyorsanız, alan içindeki yenile ikonunu kullanarak anında yeni bir Gizli Anahtar oluşturabilirsiniz.

> [!WARNING]
> **Güvenlik Önerisi:** `x-avcicms-secret-key` (`sk_live_...`) değerini asla tarayıcı koduna veya `NEXT_PUBLIC_*` ortam değişkenlerine eklemeyin. İstemci isteklerinde yalnızca `x-avcicms-client` ve `x-avcicms-api-key` kullanın; `x-avcicms-secret-key` değerini yalnızca sunucu ortamında saklayın.

### 4. Hızlı Başlangıç Şablonu
Projenizde kullanmak üzere standart ortam değişkeni şablonunu Hızlı Başlangıç kartından tek tıkla kopyalayabilirsiniz.

## Sık Karşılaşılan Sorunlar

- **Sorun:** API istekleri `401 Yetkisiz` veya `403 Yasaklı` hatası döndürüyor.
- **Çözüm:**
  - İstemci/tarayıcı isteklerinde `x-avcicms-client` ve `x-avcicms-api-key` (`pk_live_...`) başlıklarını kontrol edin.
  - Gizli anahtar gerektiren sunucu isteklerinde `x-avcicms-client` ve `x-avcicms-secret-key` (`sk_live_...`) başlıklarının doğru gönderildiğini doğrulayın.
  - Anahtar yenilendiyse sunucu ortam değişkenlerinizi güncelleyin.
