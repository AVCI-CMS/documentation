# Kurumsal Ayarlar

**Rota:** `(organization) > /organization/settings`

Bağlı varlıklara (alt satıcılara) doğru aşağı yönlü kademeli olarak etki eden üst düzey operasyonel kuralları yapılandırın.

## Yapılandırma Alanları

- **Alt Satıcı Oluşturma (Sub-Merchant):** Çalışma Alanı Yöneticisi tarafından etkinleştirilmişse, bölge yöneticilerinizin bağımsız olarak yeni alt satıcılar oluşturabilip oluşturamayacağını veya Organizasyon Yöneticisinden onay almaları gerekip gerekmediğini yapılandırabilirsiniz.
- **Veri Siloları (Çok kiracılı yalıtım / Multi-tenant isolation):** Organizasyon seviyesine atanan personelin *tüm* satıcılardan toplanan toplu (aggregated) verileri görüp göremeyeceğini veya belirli satıcılara açıkça atanmaları gerekip gerekmediğini ayarlayın (toggle).
- **API Erişimi:** Konsolide edilmiş (birleştirilmiş) satış verilerini çekmek üzere platformu kurumsal ERP'nize (SAP veya Oracle gibi) bağlamak için Kurumsal API anahtarları oluşturun.
- **[Bildirim Tercihleri](./notifications):** Organizasyonel etkinlikler ve alt satıcı aktiviteleri için SMS, E-posta veya Uygulama İçi uyarılara abone olun veya çıkış yapın.
