# Communication Settings

**Menu Path:** `Workspace > Settings > Communication`

:::info Permission Requirements
Managing communication settings requires the **Workspace:Manage** or **Workspace:Settings:View** permission.
:::

The **Communication Settings** section controls automated message delivery channels, email SMTP configurations, SMS gateway integrations, push notifications, and default FAQ behaviors.
