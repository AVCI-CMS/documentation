# Catalog & Merchandising Settings

**Menu Path:** `Workspace > Settings > Catalog`

:::info Permission Requirements
Managing catalog settings requires the **Workspace:Manage** or **Workspace:Settings:View** permission.
:::

The **Catalog Settings** panel defines the default parameters and validation rules for products, variants, ticketing events, and delivery routes created within your workspace.
