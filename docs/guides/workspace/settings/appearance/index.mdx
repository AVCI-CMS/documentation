# Workspace Appearance Settings

**Menu Path:** `Workspace > Settings > Appearance`

:::info Permission Requirements
Managing workspace appearance requires the **Workspace:Manage** or **Workspace:Settings:View** permission.
:::

The **Appearance Settings** section allows workspace administrators to customize the visual branding, logos, color palettes, and theme preferences across their administrative interface and default client views.
