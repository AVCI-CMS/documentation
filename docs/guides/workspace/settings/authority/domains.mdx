# Domains (Custom Storefront, CDN, API & Management Hostnames)

**Menu Path:** `Workspace > Settings > Authority > Domains`

:::info Permission Requirements
To manage custom domains, you must have the **Workspace:Settings:Manage** permission.
:::

The **Domains** module uses **Cloudflare for SaaS (Custom Hostnames API)** to connect your custom brand hostnames to AVCI CMS services with automatic SSL/TLS certificate provisioning and edge routing.

## Supported Target Service Types

| Target Type | Example Hostname | Required CNAME Target | Synced Workspace URL |
| :--- | :--- | :--- | :--- |
| **`STOREFRONT`** | `shop.yourbrand.com` | `cname.avcicms.com` | `workspace.url.landing` |
| **`CDN`** | `cdn.yourbrand.com` | `cdn.avcicms.com` | `workspace.url.cdn` & `url.image` |
| **`API`** | `api.yourbrand.com` | `api.avcicms.com` | `workspace.url.backend` |
| **`MANAGEMENT`** | `admin.yourbrand.com` | `app.avcicms.com` | `workspace.url.management` |

## Key Features & Configuration

### 1. Adding a Custom Domain
1. Click **"Add Domain"** and select the **Target Service Type** (`STOREFRONT`, `CDN`, `API`, or `MANAGEMENT`).
2. Enter your hostname without protocol (`cdn.yourbrand.com`, not `https://cdn.yourbrand.com`).
3. Once added, AVCI CMS registers a Cloudflare Custom Hostname and generates the required **CNAME** (routing) and **TXT** (ownership & DV SSL validation) records.

### 2. DNS Verification & Automatic SSL Provisioning
- Add the displayed **CNAME** and **TXT** records in your DNS provider (Cloudflare, GoDaddy, AWS Route53, etc.).
- Click **"Verify Now"** or wait for the automatic background monitor (which polls pending domains every 5 minutes).
- Once verified:
  - Cloudflare automatically issues and renews your SSL certificate (`SSL Active`).
  - If the domain type is `CDN`, the Go Image CDN microservice (`cdn.avcicms.com`) is immediately notified via `/internal/domains/reload` with zero downtime.
  - If the domain type is `API`, incoming REST requests to `https://api.yourbrand.com/v1/*` are automatically resolved to your workspace by hostname.

### 3. Managing Domains
- **Set Primary:** You can have multiple verified domains per service type. Setting one as **Primary** updates the corresponding Workspace URL setting automatically.
- **Remove Domain:** Deleting a domain removes both the workspace record and the Cloudflare Custom Hostname / SSL configuration.
