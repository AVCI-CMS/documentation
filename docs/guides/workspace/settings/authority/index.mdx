# Authority & Access Control

**Menu Path:** `Workspace > Settings > Authority`

:::info Permission Requirements
Managing authority settings requires the **Workspace Owner** or **Role:Manage** permission.
:::

The **Authority & Access Control** suite defines the security posture of your workspace. It allows you to manage staff accounts, create customized RBAC roles, allocate granular permissions, generate API keys, and map custom domain names.
