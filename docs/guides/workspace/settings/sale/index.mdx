# Sale & Commerce Settings

**Menu Path:** `Workspace > Settings > Sale Settings`

:::info Permission Requirements
To view or modify commerce settings, you must have the **Workspace:Settings:View** or **Workspace:Manage** permission.
:::

The **Sale Settings** module configures platform-wide transactional behaviors, including shopping cart timeouts, checkout policies, marketplace commission splits, return windows, disputes, and shipping options.
