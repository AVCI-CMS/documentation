# Data Migration & Bulk Import

**Menu Path:** `Workspace > Advanced > Data Migration`

:::info Permission Requirements
To run bulk migrations or export records, you must have the **Workspace:Manage** permission.
:::

When transferring existing business records from legacy e-commerce platforms (such as Shopify, WooCommerce, or Magento) into AVCI CMS, the **Data Migration** module simplifies bulk ingestion and backup exports.

## Bulk Import via CSV / Excel

1. **Download Sample Template:** Always download the official CSV template from the screen before uploading your file to ensure column headers match system fields (e.g. `title`, `sku`, `price`, `stock`, `category_slug`).
2. **Upload & Map Columns:** Upload your `.csv` or `.xlsx` file. The interface presents an interactive column mapping tool to reconcile any custom column titles.
3. **Dry-Run Validation:** The system pre-scans all rows and reports missing fields, duplicate SKUs, or malformed prices before writing changes to your live catalog.
4. **Execution & Rollback:** Run the import. If errors occur mid-way, an error log is generated detailing the exact rows that failed so you can correct them.

## Data Export
You can export full or filtered datasets in CSV or JSON format for offline backups, third-party ERP syncing, or financial audits.
