# Test Users & Sandbox Accounts

**Menu Path:** `Workspace > Advanced > Test Users`

:::info Permission Requirements
To manage test users, you must have the **Workspace:Manage** permission.
:::

The **Test Users** module allows workspace administrators to create simulated buyer, seller, and brand accounts. These sandbox accounts allow your QA and marketing teams to test checkout flows, role permissions, and storefront interactions without contaminating live analytics or accounting reports.

## Key Features

1. **Simulated Checkouts:** Run end-to-end checkout transactions using test credit card numbers.
2. **Analytics Exclusion:** Actions performed by test users are automatically excluded from revenue graphs and conversion funnels.
3. **One-Click Reset:** Easily purge test orders and reset buyer cart data between staging iterations.
