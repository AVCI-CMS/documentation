# Webhook Subscriptions

**Menu Path:** `Workspace > Advanced > Webhooks`

:::info Permission Requirements
Managing webhooks requires the **Workspace:Manage** or **Developer:Access** permission.
:::

Webhooks provide real-time HTTP event streaming from AVCI CMS directly to your external systems, such as custom order processing services, warehouse management systems (WMS), or customer relationship tools (CRM).

## Managing Endpoints in the Control Panel

1. Go to **Workspace > Advanced > Webhooks**.
2. Click **"Add New Webhook"**.
3. **Endpoint URL:** Enter your HTTPS destination URL (e.g. `https://api.yourstore.com/webhooks`).
4. **Subscribed Events:** Choose specific events (e.g. `order.created`, `order.paid`, `stock.depleted`) or select `*` to subscribe to all workspace events.
5. **Signing Secret:** Note the secret generated for cryptographic signature verification (`x-avci-signature`).

For developer payload formats, signature checking code, and retry policies, see the [Developer Webhooks Guide](/sdk/webhooks).
