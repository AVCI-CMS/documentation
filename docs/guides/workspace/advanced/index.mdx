# Advanced Settings

**Menu Path:** `Workspace > Advanced`

:::info Permission Requirements
To access Advanced Settings, you must have the **Workspace:Manage** or **Workspace:Settings:View** permission.
:::

The **Advanced Settings** hub centralizes low-level workspace tools, scheduled tasks, data import/export pipelines, legal compliance agreements, and developer webhooks.
