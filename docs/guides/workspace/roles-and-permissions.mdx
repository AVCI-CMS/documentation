# Roles & Canonical RBAC Permissions

**Menu Path:** `Workspace > Settings > Authority & Team`

AVCI CMS uses a tenant-isolated, **fail-closed Role-Based Access Control (RBAC)** model backed by a single canonical permission registry (`module:action` lowercase codes).

---

## Workspace Roles

| Role Code | Title | Scope & Isolation | Available Plans |
| :--- | :--- | :--- | :--- |
| `AVCI` | Platform Super Admin | Global platform health, migrations (`migration:manage`), system settings (`*`) | Platform Core |
| `WORKSPACE_OWNER` | Workspace Owner | Full control inside own workspace (`workspace:*`, excluding platform-only permissions) | Basic, Pro, Business, Enterprise |
| `WORKSPACE_ADMIN` | Operations Admin | Orders, approvals, catalog, content, tickets, team operations | Business, Enterprise |
| `WORKSPACE_EDITOR` | Content & Catalog Editor | CMS content (blog, news, pages, dictionary) and catalog entries | Pro, Business, Enterprise |
| `WORKSPACE_FINANCE` | Finance Specialist | Payouts, transactions, ledger, taxes, disputes, penalties | Pro, Business, Enterprise |
| `WORKSPACE_MERCHANT` | Marketplace Vendor | Isolated to own products, sub-orders, stock, and shipments | Enterprise |
| `WORKSPACE_BRAND` | Brand Owner | Master GTIN/EAN product catalog and authorized merchant approvals | Enterprise |
| `WORKSPACE_ORGANIZATION` | Umbrella Organization | Cooperatives, chambers, unions managing member merchants and brands | Enterprise |
| `USER` | End-User / Customer | **Never allowed in Admin Panel.** Storefront / Public API only | Pro, Business, Enterprise |

:::warning Wildcard & Platform Isolation
- `*` is reserved exclusively for `AVCI` (Platform Super Admin).
- `workspace:*` grants all tenant-scoped permissions to `WORKSPACE_OWNER`, **never** platform-only permissions (`system:manage`, `migration:view`, `migration:manage`).
- End-users (`USER`) and guests are strictly rejected from all `/management/*` endpoints.
:::

---

## Canonical Permission Codes

All backend middlewares (`auth(...)`, `authWorkspace(...)`), database `Permission` documents, and frontend guards validate against lowercase singular codes in `module:action` (or `module:subresource:action`) format.

- `system:manage`
- `migration:view`, `migration:manage` *(AVCI Platform Super Admin only)*
